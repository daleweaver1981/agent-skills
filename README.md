# Agent skills by Dale Weaver

Skills in the open [Agent Skills](https://agentskills.io) format. Each folder under `skills/` holds one `SKILL.md`.

| Skill | What it does |
|---|---|
| [check-product-reviews](skills/check-product-reviews/SKILL.md) | Judges whether a batch of product reviews is authentic or manipulated, using the free Prime Reviews Pro analyzer (MCP, no key). |
| [us-import-tariff-lookup](https://github.com/daleweaver1981/tariffmonitor-mcp/blob/main/skills/us-import-tariff-lookup/SKILL.md) | Looks up US import duty for an HTS code and origin country via the tariffmonitor MCP server. |

Every skill says what it cannot do and tells the agent not to invent a result when the service is unavailable.
